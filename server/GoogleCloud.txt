In iziiserver_restore.sh, DB_APP_PASS="" means the script does not set/change the postgres role's password (iziiserver_restore.sh:226-228) — it only creates a fresh postgres role via apt install postgresql, which has no password set. Fresh role password ≠ DSN password → password authentication failed for user "postgres".

Make the DB password match the DSN already in the service (simplest, no app config change). SSH in and run:

sudo -u postgres psql -c "ALTER ROLE postgres PASSWORD '<password-from-dsn>';"
sudo systemctl restart iziiserver

That directory is owned by the service account (set via chown -R "$SVC_USER" in the restore script), not your login user. Use sudo:

The chown step matters — if you just sudo cp, the file lands owned by root while the rest of /opt/izii_server is owned by the service user (e.g. iziiserver), which can cause the app to fail loading it depending on how it's run. After copying, restart the service to pick it up:

NGINX:
===============================
Muốn subdomain trỏ về VM mà không cần gõ :8080 thì cần thêm reverse proxy (nginx) lắng nghe ở port 80/443 rồi chuyển tiếp vào 127.0.0.1:8080 — trình duyệt mặc định dùng port 80 (http) / 443 (https), nên chỉ đổi DNS thôi sẽ không đủ.

1. Trỏ DNS — ở nhà cung cấp domain, tạo bản ghi:


A   api.yourdomain.com   →   34.129.21.244
2. Mở firewall GCP cho port 80/443:


gcloud compute firewall-rules create allow-izii-http --project iziisolution \
  --network default --allow tcp:80,tcp:443 --target-tags izii-server --source-ranges 0.0.0.0/0
3. Cài nginx trên VM và cấu hình reverse proxy:


sudo apt-get update && sudo apt-get install -y nginx

sudo tee /etc/nginx/sites-available/iziiserver > /dev/null <<'EOF'
server {
    listen 80;
    server_name api.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket support (cần cho /chat)
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
EOF

sudo ln -sf /etc/nginx/sites-available/iziiserver /etc/nginx/sites-enabled/iziiserver
sudo nginx -t && sudo systemctl restart nginx
